# ひと区切り — ポモドーロタイマー

React / JavaScript / HTML / Tailwind CSS で実装。Vite は開発・ビルドに使用します。
UIライブラリやタイマーライブラリは使っていません。

## 起動

```sh
cd pomodoro-app
pnpm install
pnpm dev
```

## 機能

- 作業25分、休憩5分のカウントダウン
- スタート、一時停止、再開、現在のモードのリセット
- 手動モード切り替え（停止して切り替え先の初期時間に戻る）
- 終了メッセージと次のモードへの切り替え（自動開始しない）
- 作業を最後まで終えた回数を表示
- 経過に応じて円が埋まる進捗表示

完了回数は今回ページを開いている間のみ保持します。再読み込みでリセットされます。
終了時刻との差で残り時間を計算し、非表示タブの更新遅延を補正します。
通知は画面内メッセージです。音やOS通知は使いません。

## タスク連携と夜間表示

「取り組むタスク」で未完了タスクを選択できます。「タスクを追加・管理する」から
既存の posse-task-app の画面を開き、追加・完了・削除を行えます。
タイマーの終了だけではタスクを自動で完了にしません。

別ポートのタスクアプリとは localStorage が分かれています。既存データは元のアプリで
「ポモドーロ用にタスクを書き出す」を押し、ポモドーロの「別のタスクアプリから引き継ぐ」
で読み込みます。これは取り込みであり、別ポート間の継続的な同期ではありません。
取り込み後はポモドーロ内で管理してください。同じIDの既存タスクは上書きしません。
タスクは保存しますが、選択中のタスクは再読み込みで未選択になります。

端末のローカル時刻が17:00〜23:59の間はダークモードです。
開いたままでも毎秒確認し、0:00になるとライトモードへ戻ります。

## 追加の自動テスト

```sh
node --test src/timer.test.js src/preferences.test.js
```

```sh
pnpm build
pnpm lint
node --test src/timer.test.js
```

画面ではスタート・停止・再開、各モードのリセット、円の進捗を確認できます。
自動テストでは時刻を進めて、25分終了、休憩終了、二重加算防止も検証します。
